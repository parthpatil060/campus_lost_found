## QR Codes

- `android_apk_qr.png`: points to the APK file hosted on the `broadcast-feature` branch.
- `ios_qr_placeholder.png`: placeholder QR that currently points to the repository branch because no installable iOS link is available in this workspace.

To create a real iPhone install QR later, replace the placeholder target with one of these:

- A TestFlight public invite link
- An App Store link
- A hosted `.ipa` manifest/install link
